Instal LYRIC AUTO LOCK

Manifest PWA sudah ditanam langsung di file index ini. Agar tombol Instal bekerja, aplikasi harus dibuka melalui alamat HTTPS atau localhost (bukan klik file HTML langsung):

  1. Letakkan index.html dan sw.js dalam satu folder.
  2. Jalankan folder melalui server lokal (localhost) atau hosting HTTPS.
  3. Buka alamatnya di Google Chrome atau Microsoft Edge.
  4. Klik tombol Instal di pojok kanan atas.

File sw.js wajib berada di folder yang sama. Browser tidak mengizinkan Service Worker dijalankan dari file://; ini aturan keamanan PWA.
